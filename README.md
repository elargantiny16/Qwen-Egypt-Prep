# Qwen-Egypt-Prep
# 🇪🇬 Qwen Build Day Egypt - Preparation & Local Guide

Welcome! This repository is the planning hub for **Qwen Build Day Egypt**, a planned 150-person AI hackathon aimed at onboarding the next generation of Egyptian developers into the open-source AI ecosystem.

## 🎯 The Mission
To provide a frictionless way for local developers to get started with Alibaba's Qwen models and build localized, impactful AI tools.

## 🛠️ Quick Start: Running Qwen Locally
For Egyptian devs looking to prepare for the hackathon, here is the fastest way to run Qwen offline:
1. Download [Ollama](https://ollama.com/)
2. Open your terminal and run: `ollama run qwen2.5:7b`
3. Start prompting! (Try asking it to translate Python comments into Arabic).
